Methodology
  • This list is hand-curated, not automated. A text search for government/police/transit terms in flagged descriptions returned many false positives — mostly complaints about police not enforcing, not about a government vehicle actually blocking a lane. Each candidate was read individually before inclusion.
  • Confirmed = the description unambiguously names the vehicle/agency and states it was parked or blocking. Likely = a plausible but less explicit read (e.g. a general claim, or an adjacent lane like a bus stop rather than the bike lane itself).
  • Confirmed bike lane / Possible bike lane badges refer to the same flag used across the rest of this dataset — see the main dashboard for that methodology.
  • This is very likely an undercount — it reflects what turned up during a single manual review pass, not an exhaustive search. It is not padded with borderline text matches to inflate the total.
